# 💬 ChatD

Um chat de conversas simples e fácil, criado com **Node.js**. Projeto focado em comunicação em tempo real com uma interface limpa e intuitiva.

## 📋 Sobre o Projeto

O **ChatD** é uma aplicação de chat desenvolvida com Node.js que permite conversas em tempo real entre usuários. O projeto foi construído com Vite como ferramenta de build e conta com uma estrutura organizada de assets para a interface.

## 🚀 Como Executar

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado (versão 14+)
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/bryanwinchezz/ChatD.git

# Acesse a pasta do projeto
cd ChatD

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse `http://localhost:5173` no navegador.

### Build para Produção

```bash
npm run build
```
